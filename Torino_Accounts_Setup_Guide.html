1
Apple Developer Account
developer.apple.com  ·  $99/year
  1. Go to developer.apple.com and click Account
  2. Sign in with your Apple ID (or create one at appleid.apple.com)
  3. Click Join the Apple Developer Program
  4. Select Enroll as Individual (your name on store) or Organization (company name — requires a D-U-N-S number)
  5. Complete identity verification
  6. Pay the $99/year fee using a card or PayPal
  7. Wait for approval — usually within 24–48 hours
  8. Once approved, go to App Store Connect → Users and Access → Invite developer

📋 What to send us after account creation:

  • Apple ID email address used to create the account
  • Invite the developer email to your team as Admin in App Store Connect
  • Apple Developer Team ID (found under Membership in developer.apple.com)
⚠️ Use a business Apple ID, not a personal one, to keep your app ownership separate.
2
Google Play Console
play.google.com/console  ·  $25 one-time
  1. Go to play.google.com/console
  2. Sign in with a Google account (use a business Gmail such as torino@gmail.com)
  3. Click Get Started
  4. Enter your developer name — this will appear publicly on the Play Store
  5. Accept the Developer Distribution Agreement
  6. Pay the $25 one-time registration fee
  7. Fill in your contact details (address, phone number)
  8. Account is typically activated within a few hours
  9. Go to Users and Permissions → Invite the developer as Admin

📋 What to send us after account creation:

  • Gmail address used for the Play Console
  • Invite developer email via Users and Permissions → Grant Admin access
💡 Use a dedicated business Gmail for this account, not a personal Gmail.
3
AWS — Amazon Web Services
aws.amazon.com  ·  Pay as you use (free tier for most services)
  1. Go to aws.amazon.com and click Create an AWS Account
  2. Enter your email address and choose an account name: Torino
  3. Set a strong root password and save it somewhere secure
  4. Enter your contact information — select Personal or Business
  5. Add a credit or debit card (AWS only charges for usage, free tier applies to most services)
  6. Complete phone number verification
  7. Select the Basic (Free) support plan
  8. Your account will be activated within minutes
  9. Once inside, go to IAM → Users → Create User
  10. Name the user torino-dev, attach policy: AdministratorAccess
  11. Under Security Credentials, click Create Access Key → copy both keys

📋 What to send us after account creation:

  • IAM User Access Key ID
  • IAM User Secret Access Key
  • Your AWS account region preference (e.g., us-east-1)
⚠️ Never share your root account credentials. Always use the IAM user keys created in Step 10.
4
Agora — Live Video & Audio
agora.io  ·  Free (10,000 minutes/month)
  1. Go to agora.io and click Sign Up
  2. Register with your email and a password, or sign in with Google
  3. Verify your email address
  4. Once in the dashboard, click Create Project
  5. Enter project name: Torino
  6. Select Secured mode (recommended for production)
  7. Click Submit
  8. Click on the project → copy the App ID and App Certificate

📋 What to send us after account creation:

  • Agora App ID
  • Agora App Certificate
💡 Agora provides 10,000 free minutes per month — more than enough for development and early users.
5
Gemini API — Google AI
aistudio.google.com  ·  Free tier available
  1. Go to aistudio.google.com
  2. Sign in with your Google account
  3. Click Get API Key from the left sidebar
  4. Click Create API Key
  5. Select an existing Google Cloud project or create a new one named Torino
  6. Your API Key will be generated — copy it immediately and save it

📋 What to send us after account creation:

  • Gemini API Key
⚠️ Keep this key private at all times. Do not share it in public messages or emails. Send it through a secure method.
💡 The free tier covers a generous number of requests — ideal for development and moderate usage.
6
Stripe — Payment Processing
stripe.com  ·  2.9% + $0.30 per transaction
  1. Go to stripe.com and click Start now
  2. Enter your email, full name, and country
  3. Set a strong password and verify your email
  4. Complete your business profile:
    • Business type: Individual or Company
    • Industry: Education or Software
    • Website: your app link or placeholder
  5. Add your bank account details for receiving payouts
  6. Submit any identity verification documents if requested
  7. Go to Developers → API Keys and copy both keys

📋 What to send us after account creation:

  • Stripe Publishable Key (starts with pk_live_...)
  • Stripe Secret Key (starts with sk_live_...)
  • Stripe Webhook Secret (we will set this up together)
⚠️ The Secret Key must never be shared publicly. Send it only through a secure private channel.
💡 No monthly fee. Stripe only charges when a payment is processed (2.9% + $0.30 per transaction).

🔒 How to Share Credentials Securely

All credentials (API keys, access keys, passwords) must be shared through a secure method only. Please avoid sending them through regular email or messaging apps.

  • Recommended: Share via 1Password or Bitwarden — create a shared vault and add us
  • Acceptable: Send through an encrypted messaging app such as Signal or Telegram (secret chat)
  • Avoid: Regular Gmail, WhatsApp messages, or plain text — these are not secure for sensitive credentials
  • Never include API keys or passwords in a regular email body
